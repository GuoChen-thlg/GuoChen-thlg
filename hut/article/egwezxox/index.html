一些常用的 CSS 片段

清除浮动

.clearfix::after {
  content: '';
  display: block;
  width: 0;
  height: 0;
  clear: both;
  font-size: 0;
  visibility: hidden;
  overflow: hidden;
}

隐藏滚动条

.hidder-scrollbar {
  /* 兼容IE10+ */
  -ms-overflow-style: none;
  /* 兼容火狐 */
  scrollbar-width: none;
}
.hidder-scrollbar::-webkit-scrollbar {
  /* 兼容Chrome */
  display: none;
}

文字超出省略号

.omit {
  /* 自定义行数 */
  display: -webkit-box;
  -webkit-line-clamp: 1;
  word-break: break-all;
  -webkit-box-orient: vertical;
  overflow: hidden;
  text-overflow: ellipsis;
}
.omit {
  /* 单行 */
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
